README

Practice & "To learn"

Every card sits in a box from 0 to 5, a spaced-repetition schedule. New cards start in box 0, due immediately. To learn on the home screen is simply the count of cards whose due date has already passed - box 0 cards plus anything whose review interval has come back around.

Tapping Practice → Start practicing studies only those due cards by default. If nothing is due, you'll see a "Nothing due right now" screen with a Practice all cards anyway option, which is the only way to study cards that aren't due yet.

Answering Knew it moves a card up one box and pushes its due date out (box intervals: 1, 3, 7, 16, 35 days). Answering Didn't know (or typing the wrong word) drops it straight back to box 0, due immediately, and requeues it in the same session: the first miss brings it back after at least 10 other cards (or at the very end if fewer than 10 remain), and missing it again moves it into a review pass at the end of the session under a "Let's review the cards you didn't know" heading, where it keeps recycling until you get it right.

The "done" count and progress bar only advance on a correct answer - a card you missed stays counted as remaining (however many times it recycles) until you actually get it right, so the bar always reflects real progress rather than raw attempts.

Mastery bar

The mastery bar groups every card into one of three tiers based on its box: New (box 0), Learning (box 1-2), and Mastered (box 3+). Tapping a segment or its legend opens Manage cards pre-filtered to that tier.

Practice modes

Choose Flip Spanish card, Flip Translation card, or Type the Spanish word in Practice setup. Your last choice, along with your deck selection, is remembered for next time.

In Flip Spanish card and Flip Translation card, tap the card to flip it, then swipe right (or tap Knew it) or swipe left (or tap Didn't know) to answer.

In Type the Spanish word, the card shows the translation - type the Spanish word into the field below it, then tap Check (enabled once you've typed something) to flip the card and check your answer, or tap I don't know to reveal it straight away without guessing. Checking ignores case, accent marks, ñ vs n, and ¡¿!? punctuation, so typing without a Spanish keyboard still counts as correct. There's no Knew it / Didn't know here: a correct typed answer counts as knew it, an incorrect one or I don't know counts as didn't know, then tap Next to continue.

Once a card is flipped, a pencil icon appears in its top-right corner - tap it to edit that card without leaving the lesson. Saving your changes (or backing out without saving) drops you right back into the same lesson, on the same card, with your progress untouched.

Card decks

Decks are tags you can put on a card - a card can belong to any number of decks, or none. Each deck gets a random color as soon as you create it, shown as a tinted glass background on its row and on its tag chips wherever it's listed, so it's easy to spot at a glance.

Practice setup and Manage cards both let you filter by deck, including a "No card deck" bucket for untagged cards. In Practice setup, use the small Select all / Unselect chips to quickly check or clear every deck - Start practicing stays disabled until at least one is selected. Tapping a deck from the Card decks screen jumps straight into Manage cards filtered to it. Deleting a deck removes that tag from its cards - the cards themselves stay put.

In Add card, Ask Gemini to create a deck opens a small form (theme, word count, translation language, deck name) and, once you've checked the box confirming you know how to import the result, copies a matching request to your clipboard and opens Gemini's web app in a new tab - paste the request into Gemini's message box and send it there. The request asks Gemini to generate an actual downloadable .txt file already in this app's import format, so once Gemini replies you just download that file and bring it in with Import. This button only appears when adding a brand-new card, not while editing an existing one.

Manage cards (Cards tab)

Search and filter by deck or mastery, then tap any card's row to open a flip-able preview - same size and style as the practice card - to check its translation and notes without leaving the list. Swipe a row left to reveal Edit / Delete for that card. Tap Select to check off several cards and delete them together - Select all toggles to Unselect all once everything's checked - or tap + Add card (below the filters) to add a new one; this is now the only way into Add card, which no longer has its own tab. Editing a card shows a Delete option in its own top-right corner instead.

Card of the day

The home screen features one card, picked at random and kept the same all day. Tap it to flip between the word and its translation/notes, just like in practice.

Keep practicing & Recently added

Keep practicing lists cards you've recently gotten wrong (failed back down to box 0), most recent first, up to 20. Recently added shows your newest cards instead, but only when nothing is currently struggling - only one of the two lists is shown at a time. Both start collapsed to 3 rows with a "Show more" toggle.

Tap a word in either list to open the same flip-able card preview as Manage cards, without leaving the home screen.

Notes

The Notes tab is a single freeform notepad - anything typed there saves automatically and travels with Export/Import alongside your cards and streak, so it survives moving to a new device.

Export / Import

Export saves a plain-text file in Anki's tab-separated note format (word, translation, notes, deck tags, box, due date, reviewed), so it opens directly in Anki too. Deck memberships are stored as deck::Name tags - a card in several decks gets several tags. Your streak and notepad are saved in header comment lines.

Import reads that same format (older JSON exports still work too). Matching is by word + translation, case-insensitive: a duplicate isn't re-added, but any new deck tags on it are merged in. Missing decks mentioned in tags are created automatically. If it's been a week since your last export, the app will offer to back up on launch. A streak saved in the file is only adopted if your current streak is 0, and an imported notepad only if yours is currently empty - so importing cards never overwrites progress you're already building on this device.
